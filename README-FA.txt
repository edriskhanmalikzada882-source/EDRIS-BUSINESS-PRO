EDRIS BUSINESS PRO - نسخه آغازین 1.0

این بسته یک نمونه اولیه PWA و آفلاین است، نه نسخه نهایی آماده فروش.

امکانات فعلی:
- رابط راست‌به‌چپ و واکنش‌گرا
- داشبورد ابتدایی
- ثبت مشتری، فروش، مصرف و اجناس
- ذخیره‌سازی محلی با IndexedDB
- کش فایل‌های برنامه با Service Worker
- نمایش وضعیت آنلاین/آفلاین

روش آزمایش:
1) فایل‌ها را در یک مخزن GitHub آپلود کنید.
2) GitHub Pages را برای شاخه مورد نظر فعال کنید.
3) لینک HTTPS ساخته‌شده را باز کنید.
4) در موبایل از گزینه Add to Home Screen / افزودن به صفحه اصلی استفاده کنید.

محدودیت‌های مهم:
- داده‌ها فقط در مرورگر و دستگاه فعلی ذخیره می‌شوند.
- همگام‌سازی میان دستگاه‌ها هنوز ساخته نشده است.
- ورود کاربران، نقش‌ها، امنیت سرور، جداسازی واقعی شرکت‌ها،
  لایسنس و پرداخت هنوز پیاده‌سازی نشده‌اند.
- برای فروش تجارتی، پیش از عرضه عمومی باید بک‌اند امن،
  احراز هویت، کنترل دسترسی، رمزنگاری انتقال، پشتیبان‌گیری،
  تست همگام‌سازی و بررسی امنیتی اضافه شود.
- از وارد کردن اطلاعات حساس و حسابداری واقعی در این نسخه آزمایشی خودداری کنید.

معماری پیشنهادی نسخه تولیدی:
Frontend: PWA (قابل نصب روی iOS / Android / Desktop)
Local DB: IndexedDB
Backend API: TypeScript/Node.js یا معادل نگهداری‌پذیر
Server DB: PostgreSQL با جداسازی tenant_id و Row-Level Security
Sync: صف عملیات محلی، شناسه یکتای عملیات، نسخه رکورد و سیاست حل تعارض
Authentication: نشست امن، نقش‌ها و مجوزهای سمت سرور
Backups: نسخه پشتیبان رمزگذاری‌شده و آزمون بازیابی
